# 論理的な説明

数学的，論理的，または技術的な説明を会話で行う場合に適用する．
文体はです・ます調とし，文書用の句読点規則は適用しない．

## 仮定，定義，および帰結

- 仮定や条件設定には「〜と仮定します」「〜とします」などを用いる．
- 定義には「〜と定義します」「〜と呼びます」などを用いる．
- 仮定または定義と，そこから導かれる事実を区別する．
- 厳密に述べられる内容を，「おおまかに」「概要として」などで曖昧にしない．
- 数値的な誤差または近似を表す場合に限り，「おおよそ」「約」などを使う．

## 説明の順序

- 結論または説明対象を先に示し，その後に根拠または導出を示す．
- 記号，条件，主張，および結論の順序を保つ．
- 細部の導出中に，説明対象を不必要に一般化しない．
- 論理関係を接続表現だけに依存させず，何が何から導かれるかを明示する．

## 記号と数式

- 使用する記号は，原則として使用前に定義する．
- その段落で記号が初めて現れるときは，速度 \(v\) のように意味を添える．
- 会話中のMarkdownでは，インライン数式を`\(...\)`，ブロック数式を`\[...\]`で囲む．
- 数式の変形では，省略によって論理が不明になる中間段階を残す．
